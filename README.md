# Paras Chavan — Portfolio

A personal portfolio website for Paras Chavan, a software engineer focused on backend systems, full-stack applications, cloud infrastructure, and AI-powered products.

**Live Demo:** [portfolio-hi8g.onrender.com](https://portfolio-hi8g.onrender.com/)

## Built With

- Next.js 15
- React 19
- TypeScript
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` — Start the development server
- `npm run build` — Create a production build
- `npm start` — Start the production server
- `npm run lint` — Run ESLint
